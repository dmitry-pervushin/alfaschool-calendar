# Календарь Alfa School для Home Assistant

Экспорт расписания из `my.alfaschool.ru` в iCalendar (`.ics`). Python 3.9+,
без дополнительных библиотек. Вход обычной HTML-формой; cookies живут только
в памяти процесса. Логин и пароль берутся из окружения и в календарь не попадают.

```bash
export ALFASCHOOL_USERNAME='ваш email'
read -rs -p 'Пароль Alfa School: ' ALFASCHOOL_PASSWORD
export ALFASCHOOL_PASSWORD
python3 alfaschool_calendar.py --output output/alfaschool.ics
```

Для постоянного обновления добавьте `--interval-hours 24` (раз в сутки),
`--interval-hours 8` или `--interval-hours 4`. Первый опрос выполняется сразу;
следующий — через указанный интервал после завершения предыдущего.
Процесс должен оставаться запущенным, например под управлением сервиса.
Альтернатива: однократный запуск через планировщик NAS/cron каждые N часов.
Постоянный сервис и планировщик одновременно не нужны.

По умолчанию каждый опрос заново вычисляет окно от 30 дней назад до 90 дней
вперёд по московскому времени. Для истории задайте даты явно:

```bash
python3 alfaschool_calendar.py --start 2025-10-01 --end 2025-10-31 \
  --output output/history-2025-10.ics
```

Скрипт читает месячные страницы расписания. Уроки на границах месяцев
дедуплицируются по ID; UID сохраняется между обновлениями. Даты переводятся
из московского времени в UTC, календарный клиент отображает свой часовой пояс.
Блоки «Занятый период» не являются занятиями и не экспортируются.
Явно отменённые занятия получают `STATUS:CANCELLED`; остальные сохраняют
описание состояния с сайта. Повторяющиеся занятия не выдумываются:
выгружаются только опубликованные записи в выбранном окне.

Файл заменяется атомарно только после загрузки всех месяцев. Ошибка входа,
сети или распознавания страницы сохраняет предыдущий файл. В режиме опроса
ошибка выводится в stderr, повтор происходит через выбранный интервал.
Пустое, но успешно прочитанное расписание даёт корректный пустой календарь.

## Подключение к Home Assistant

Нужно разместить `.ics` по HTTP-адресу, доступному из HA. Например,
если экспортёр имеет доступ к каталогу `/config/www` вашей установки HA:

```bash
python3 alfaschool_calendar.py --interval-hours 8 \
  --output /config/www/alfaschool.ics
```

В HA: **Настройки → Устройства и службы → Добавить интеграцию → Remote Calendar**.
Название: `Alfa School`, URL: `http://АДРЕС_HA:8123/local/alfaschool.ics`.
Логин школы туда вводить не нужно: он нужен только экспортёру.
Файлы HA `/local/` доступны без авторизации; размещайте календарь там,
только если такая доступность расписания приемлема. Альтернатива — отдельный
HTTP-сервер в домашней сети, при необходимости с HTTP Basic Authentication.

Remote Calendar по умолчанию обновляется раз в 24 часа. Для опроса каждые 8 часов
отключите **Enable polling for changes** в системных параметрах интеграции и
создайте автоматизацию (замените entity_id фактическим):

```yaml
alias: Обновлять календарь Alfa School
triggers:
  - trigger: time_pattern
    hours: "/8"
    minutes: "5"
actions:
  - action: homeassistant.update_entity
    target:
      entity_id: calendar.alfa_school
mode: single
```

Для 4 часов используйте `hours: "/4"`. Для суток можно оставить стандартный
опрос HA. Экспортёр и HA имеют отдельные интервалы: HA читает последнюю
выгрузку, поэтому изменения появятся после следующего экспорта и чтения HA.

Документация: https://www.home-assistant.io/integrations/remote_calendar/

В существующей карточке `custom:outlook-calendar-card` календарь появится
автоматически, если список календарей не ограничен явно. Иначе добавьте:

```yaml
calendars:
  - entity: calendar.alfa_school
```

Проверки: `python3 -m unittest -v`.
